# Настройка Supabase

1. Создайте проект Supabase.
2. Откройте **SQL Editor** и выполните `supabase/schema.sql`.
3. В **Authentication → Users** создайте пользователей. Роль выдавайте доверенным серверным процессом в `app_metadata.role` со значением `admin`, `curator` или `student`. Не используйте `user_metadata` для ролей.
4. В кабинете куратора на сайте введите Project URL и anon/publishable key из **Project Settings → API**.
5. Проверьте политики RLS на тестовых аккаунтах до добавления реальных персональных данных.

## Текущее ограничение
HTML-панель выполняет Supabase Auth sign-in, но управление материалами и флагами доступа в текущей сборке локальное (localStorage). SQL схема подготовляет серверные таблицы и политики, но UI ещё не выполняет CRUD запросы к ним и не загружает файлы в Storage. Не считайте локальные переключатели блокировкой пользователей на всех устройствах.
